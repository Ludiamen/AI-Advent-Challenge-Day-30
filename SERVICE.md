# Приватный AI-сервис: как подключиться

Сервис — шлюз `service.py` перед локальной Ollama на ноутбуке в домашней сети.
Модель одна — `loc-rag-docs` (`qwen3.5:4b`, оптимизированная в Дне 29).
Запросы не уходят с машины: Ollama слушает только 127.0.0.1, шлюз работает в
офлайн-режиме.

## Адрес и сертификат

- Адрес: `https://<адрес ноутбука в домашней сети>:8443` — его печатает `python
  cli.py --сервис-сертификат` (строка «Адреса и имена»).
- Сертификат выпущен своим центром. Клиенту нужен файл центра
  `memory/service/tls/ca.crt` (открытый, его можно раздавать). Закрытые ключи
  центра и сервера остаются на ноутбуке.
- Сменился адрес ноутбука (DHCP, другая сеть) — `python cli.py
  --сервис-сертификат` и `python cli.py --сервис перезапуск`: центр прежний,
  `ca.crt` клиентам менять не нужно.

## Ключи

```bash
python cli.py --сервис-ключ ИМЯ --права чат                  # чат
python cli.py --сервис-ключ ИМЯ --права чат,документы        # и ответ по документам
python cli.py --сервис-ключ ИМЯ --права админ                # страница /admin
python cli.py --сервис-ключи                                 # имена и права (самих ключей нет)
python cli.py --сервис-отозвать ИМЯ
```

Ключ показывается один раз; на диске хранится только его хэш. Передаётся
заголовком `Authorization: Bearer sk-day30-…`.

## Примеры

```bash
A=https://192.168.1.43:8443; K=sk-day30-…
curl --cacert ca.crt $A/health
curl --cacert ca.crt -H "Authorization: Bearer $K" $A/v1/models
curl --cacert ca.crt -H "Authorization: Bearer $K" -H 'Content-Type: application/json' \
     -d '{"messages":[{"role":"user","content":"Что такое SLA?"}],"max_tokens":200}' $A/v1/chat/completions
curl -N --cacert ca.crt -H "Authorization: Bearer $K" -H 'Content-Type: application/json' \
     -d '{"stream":true,"messages":[{"role":"user","content":"Что такое SLA?"}]}' $A/v1/chat/completions
curl --cacert ca.crt -H "Authorization: Bearer $K" -H 'Content-Type: application/json' \
     -d '{"question":"До какого числа нужно оплачивать услуги связи по договору VPN с Ростелекомом?"}' \
     $A/v1/documents/answer
```

```python
import httpx
from openai import OpenAI

клиент = OpenAI(base_url="https://192.168.1.43:8443/v1", api_key="sk-day30-…",
                http_client=httpx.Client(verify="ca.crt", timeout=600))
print(клиент.chat.completions.create(model="loc-rag-docs",
      messages=[{"role": "user", "content": "Что такое SLA?"}]).choices[0].message.content)
```

## Страницы

- `/chat` — чат и ответ по документам. Ключ вводится в поле (хранится только во
  вкладке) или приходит в ссылке `…/chat#key=sk-day30-…`: часть после `#` на
  сервер не уходит, страница кладёт ключ в память вкладки и стирает его из
  адресной строки. Так удобно открывать с телефона.
- `/admin` — состояние (ключ с правом «админ»): служба, сертификат, лимиты,
  очередь в реальном времени, память раннера, журнал сети, ключи, клиенты по
  адресам, журнал запросов, нагрузка.

## Лимиты и отказы

| Что | Предел | Отказ |
|---|---|---|
| подсеть клиента | 127.0.0.0/8, 192.168.1.0/24, 172.17.0.0/16 (`service.json`) | 403 `forbidden_network` — до проверки ключа |
| ключ | есть, не отозван | 401 `missing_api_key` / `invalid_api_key` |
| права | чат / документы / админ | 403 `permission_denied` |
| запросов на ключ | 6 в минуту ко всем `/v1/*` | 429 `rate_limited`, `Retry-After` |
| очередь | 1 генерация + 4 ждут | 429 `queue_full`, `Retry-After` |
| вход | ≤ 3400 токенов (окно 4096 − ответ 600 − запас) | 413 `context_length_exceeded` — до модели |
| ответ | `max_tokens` ≤ 600 | больше — урезается, заголовок `X-Max-Tokens-Clamped` |
| тело запроса | ≤ 256 КБ | 413 `request_too_large` |
| вопрос по документам | ≤ 1000 символов | 413 `question_too_long` |
| генерация | ≤ 600 с | 504 `timeout` |

`Retry-After` — оценка сервиса: медиана последних 20 генераций × очередь.
После коротких запросов она занижена, поэтому повторяйте до общего срока
(клиент нагрузки ждёт до 20 минут), а не ограничивайте число попыток.

Все отказы — в формате OpenAI: `{"error": {"message", "type", "code"}}`, текст
по-русски. Положение в очереди видно в заголовках `X-Queue-Position` и
`X-Queue-Wait`, а в потоке — в комментарии `: очередь N`. Если закрыть
соединение посреди потока, генерация прерывается и место в очереди
освобождается.

## Память

Модель занимает около 2,9 ГБ. Кроме неё `llama-server` в Ollama копит кэш
промптов недавних запросов вместе с контрольными точками состояния, по 100–200
МБ на запрос. Предел кэша — 8 ГБ по умолчанию: под долгой нагрузкой раннер
займёт до ≈ 11 ГБ, а через 30 минут простоя выгрузится. Предел задаёт
переменная `llama-server` `LLAMA_ARG_CACHE_RAM` (в МиБ; так пишет его справка).
Доходит ли она до раннера, если задать её процессу Ollama, этот день не
проверял: службу Ollama он не трогал.
